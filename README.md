# i · EBENE · INPUT · RAW · Träger

Der Ordner **i/** ist eine reine Eingabe‑Ebene innerhalb des iki1uc‑Systems.
Er dient als **RAW‑Träger**, der unverarbeitete Daten aufnimmt, speichert,
sichtbar macht und strukturiert.

i ist vollständig unabhängig von:

- ORT
- WELT
- NC²
- TMP
- ALL
- VECTOR
- HDF
- KI
- UNI

i ist eine **Basis‑Ebene**, die ausschließlich Rohdaten trägt und darstellt.

## Funktionen

### 1. RAW‑Träger
`RAW.tmp` speichert unverarbeitete Daten.

### 2. RAW‑Scan
`RAW.scan` liest alle RAW‑Daten ein und erzeugt eine Übersicht.

### 3. RAW‑Map
`RAW.map` ordnet die Daten in Ebenen.

### 4. RAW‑Pipe
`RAW.pipe` definiert die Reihenfolge der Darstellung.

### 5. RAW‑State
`RAW.state` zeigt den Zustand der Ebene.

### 6. ID‑System
`id.html` zeigt Struktur, Status und Inhalt.

### 7. Index‑System
`index.html` lädt alle RAW‑Dateien und zeigt sie als Panels.

---

## Zweck

Die EBENE **i/** dient als:

- RAW‑Eingabe  
- Daten‑Träger  
- Rohdaten‑Speicher  
- Scan‑Ebene  
- Basis‑Ebene  
- Vorstufe für Operatoren  
- Vorstufe für NC²  
- Vorstufe für Portal
